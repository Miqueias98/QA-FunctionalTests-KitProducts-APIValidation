# 🧪 QA – Testes Funcionais de API: Validação do Endpoint de Criação de Kits de Produtos

## 📖 Visão Geral
Este projeto apresenta testes funcionais manuais realizados para validar o comportamento do endpoint `/api/v1/kit`.  
O objetivo é verificar se o sistema responde corretamente ao adicionar diferentes quantidades de produtos a um kit, garantindo que os limites definidos pela regra de negócio sejam respeitados.

---

## 🎯 Objetivo
Validar o comportamento da API na criação de kits, analisando as respostas do servidor para diferentes volumes de produtos e garantindo o retorno adequado de mensagens de sucesso e erro.

---

## ⚙️ Técnicas e Ferramentas Utilizadas
- Testes funcionais manuais  
- Análise de classes de equivalência e valores-limite  
- Postman / API Testing  
- Planilha de casos de teste (.xlsx)

---

## 🧩 Estrutura do Projeto
- **Miqueias Ferreira, 4º sprint, turma 10.xlsx** → Contém os casos de teste, resultados esperados e reais, e o status final de aprovação.  
- Cada caso de teste descreve:
  - Título e objetivo  
  - Etapas de execução  
  - Corpo da requisição (JSON)  
  - Resultado esperado e real  
  - Status final (Aprovado / Reprovado)  

---

## 🚀 Como Executar / Testar
1. Abra o arquivo `.xlsx` fornecido.  
2. Siga as etapas descritas em cada caso de teste.  
3. Envie as requisições via Postman (ou ferramenta similar).  
4. Compare o resultado real com o esperado.  
5. Registre o status final no documento.

---

## 📊 Resultados
- Total de casos: 50
- Casos aprovados: 34
-  Casos reprovados : 16
- Nenhum bug crítico encontrado.  
- Endpoint respondeu corretamente aos limites definidos (até 30 produtos permitidos).
